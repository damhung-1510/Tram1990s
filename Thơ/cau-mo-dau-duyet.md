# Câu mở đầu và mẫu ngắt nhịp ElevenLabs (chờ duyệt)

## 1. Mẫu ngắt nhịp: "Yêu nhau chẳng quản lầm than"

**Mẫu A: ấm, kiên định (ElevenLabs v3)**
```
[warmly] Yêu nhau chẳng quản lầm than, [short pause]
mấy sông cũng lội, [pause] mấy ngàn cũng qua!
```

**Mẫu B: tâm tình, chậm, hơi ngân (ElevenLabs v3)**
```
[softly] Yêu nhau... chẳng quản lầm than, [pause]
mấy sông cũng lội... [short pause] mấy ngàn cũng qua.
```

**Mẫu C: không dùng tag, chỉ ngắt bằng dấu (hợp Multilingual v2)**
```
Yêu nhau chẳng quản lầm than,
<break time="0.6s" />
mấy sông cũng lội, mấy ngàn cũng qua!
```
